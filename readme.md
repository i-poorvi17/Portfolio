# Poorvi Agrawal — Portfolio

Cybersecurity student portfolio — HTML/CSS/JS site showcasing my projects, skills, and TryHackMe/HTB learning progress.

🔗 **Live site:** [github.com/i-poorvi17](https://github.com/i-poorvi17)

## About

I'm a B.Tech CSE student focused on cybersecurity — specifically penetration testing, digital forensics, and cloud security. This portfolio tracks my projects, skills, and hands-on learning through platforms like TryHackMe and HackTheBox.

## Built With

- HTML5
- CSS3 (custom design system, no frameworks)
- Vanilla JavaScript

## Features

- Animated network-graph hero visualization (canvas)
- Typed-text role cycling
- Filterable project showcase (Security / Dev)
- Interactive skill tag cloud
- Learning path timeline
- Fully responsive layout

## Structure

```
portfolio/
├── index.html      # page structure & content
├── style.css       # design tokens, layout, animations
└── script.js       # skills/projects data + interactivity
```

## Editing Content

All editable content lives in `script.js` at the top:
- `SKILLS` — skill categories and tags
- `PROJECTS` — project cards (title, description, links)
- `TIMELINE` — learning path entries

Colors and fonts are controlled via CSS variables in `style.css` under `:root`.
